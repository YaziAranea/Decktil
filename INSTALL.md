# Установка на Steam Deck

## Через окно настроек

1. Перейдите на рабочий стол Steam Deck. Запустите Steam и завершите игру, если она открыта.
2. [Откройте последний релиз](https://github.com/YaziAranea/Decktil/releases/latest) и скачайте **Decktil.tar.gz** в разделе **Assets**. В Dolphin выберите «Распаковать», откройте распакованную папку и запустите **Decktil.desktop**. Если KDE попросит подтвердить запуск скачанного ярлыка, выберите «Выполнить».
3. Нажмите **Включить Decktil**, затем **Подготовить ярлык и шаблон**. В библиотеке Steam откройте страницу **Deck Plasma Keyboard Controls**, нажмите значок контроллера, выберите **Шаблоны → Deck Plasma Keyboard** и примените раскладку. Вернитесь в мастер и нажмите **Проверить и включить Decktil**.
4. Убедитесь, что напротив рабочего стола KDE, Big Picture и игрового режима SteamOS указано **Decktil**. Можно вернуться в игровой режим, открыть поиск Steam и попробовать **Steam + X**. В верхнем поиске **R1** ставит пробел, **X** стирает.
5. Для возврата откройте **Decktil** из меню приложений KDE и нажмите **Вернуть Steam**. Это переключит все три режима. В том же окне можно снова выбрать Decktil.

Установка и работа панели проверялись на SteamOS 3.9.5 с Plasma Keyboard 6.7.3. Мастер запускается на рабочем столе KDE Plasma Wayland от обычного пользователя. Для первой установки может понадобиться интернет. Если в SteamOS отсутствуют привязки Python к Qt, мастер получает совместимые пакеты для этой версии системы и проверяет их перед установкой в домашнюю папку.

**Обновление с прежней версии.** Распакуйте новый релиз и откройте его **Decktil.desktop**. Нажмите **Обновить Decktil** или **Включить Decktil**, если раньше был настроен только рабочий стол. Сохранённый шаблон Steam используется повторно. Настройки оформления и личный словарь хранятся отдельно.

Чтобы изменить цвета, откройте **Decktil › Оформление**. Выберите образец или раскройте **Настроить цвета и градиент**. Проверьте буквы в предпросмотре и нажмите **Применить**. **Системная** возвращает оформление KDE, **Своя** — сохранённый градиент. Палитра хранится в `$XDG_CONFIG_HOME/decktil/appearance.ini`, по умолчанию в `~/.config/decktil/appearance.ini`.

Ряд **1–0** включён на обеих буквенных раскладках. Чтобы скрыть или вернуть его, в **Decktil › Оформление** измените флажок **Показывать ряд цифр 1–0 над буквами** и нажмите **Применить**.

В **Decktil › Личный словарь** можно включить запоминание слов и сочетаний. Завершённое слово доступно для подсказок после первого ввода. При новой установке обучение выключено. Пауза сохраняет уже выученные слова. Кнопка **Очистить личный словарь** удаляет их после подтверждения. Личные данные находятся в `$XDG_DATA_HOME/decktil/personal.sqlite3`, обычно это `~/.local/share/decktil/personal.sqlite3`. Этот файл сохраняется при обновлении адаптера.

## Chrome на рабочем столе

При вводе адреса нажмите и отпустите **B**. Можно сразу выбрать правым трекпадом одну из подсказок самого Chrome. При возврате указателя в ту же активную строку Decktil открывается снова, если Chrome предоставляет границы поля через интерфейс доступности. Также работает вызов через **X** или **Steam + X**.

Для Google Chrome из Discover (Flatpak) откройте в менеджере **Автооткрытие в Chrome**, нажмите **Включить для Chrome**, затем полностью выйдите из Chrome через его меню и вновь откройте браузер. Эти параметры действуют только для Chrome. В том же окне кнопка **Вернуть прежние настройки** отменяет изменения, внесённые менеджером. Кнопкой **B** можно пользоваться и без автооткрытия.

Для определения положения поля Decktil запрашивает его роль, состояние и границы. Адрес и текст страницы для этого не нужны.

## Через Konsole

Откройте Konsole в распакованном каталоге с `setup.py`. Запустите Steam и закройте работающие игры.

Понадобятся Plasma Keyboard с установленными файлами раскладок, Python 3 с PyGObject и dbus-python, GLibUnix, xdotool, kreadconfig6, kwriteconfig6, qdbus6, steamos-add-to-steam и пользовательский systemd. Для ввода нужен доступ на чтение к устройству hidraw встроенного контроллера. Для вибрации нужен также доступ на запись. Для настольного адаптера нужен сеанс Wayland. Полноэкранная клавиатура использует Gamescope в игровом режиме SteamOS и пользовательское виртуальное устройство ввода в Big Picture на KDE.

Для закрытия клавиатуры кнопкой **X** после удаления текста в Codex используйте обычный режим автоматического показа Plasma. В режиме «Всегда показывать» KWin может снова открыть панель, пока поле сохраняет фокус.

У установленного адаптера команды `python3 setup.py mode steam` и `python3 setup.py mode plasma` выполняют тот же выбор, что и кнопки менеджера. Команда `python3 setup.py status` показывает фактический режим.

1. Выполните `python3 setup.py prepare`. Команда создаст локальную копию выбранной настольной раскладки Steam и добавит в библиотеку служебный ярлык **Deck Plasma Keyboard Controls**.
2. Откройте этот ярлык в библиотеке Steam. Перейдите в настройки раскладки контроллера, откройте вкладку **Шаблоны / Templates**, выберите **Deck Plasma Keyboard** и примените. Если шаблон ещё не появился, полностью закройте Steam через меню **Steam > Выход**, выполните `python3 setup.py bind` и запустите Steam снова. Этот запасной способ привязывает шаблон только к служебному ярлыку. Если им пользуются несколько учётных записей или для ярлыка уже назначена другая раскладка, выберите шаблон через интерфейс Steam.
3. Верните фокус в Konsole и выполните `python3 setup.py enable`. Установщик проверит, что Steam загрузил нужный шаблон и вернул обычное управление. Затем включатся настольный адаптер и службы полноэкранного Steam.
4. В настройках экранной клавиатуры Plasma включите русский язык и английский (США). Откройте текстовое поле в приложении Wayland и нажмите **Steam + X**.

Служебный ярлык запускать вручную не нужно. Храните его в библиотеке вместе с назначенным шаблоном. Адаптер получает его AppID из локальной библиотеки. Если Steam ещё не сохранил ярлык, закройте и снова откройте Steam. Если ярлык отсутствует, вручную добавьте в библиотеку как стороннюю игру исполняемый файл, путь к которому напечатал `prepare`.

Если установщик не находит используемую раскладку, сохраните её как личную настольную раскладку встроенного контроллера через Steam и повторите `prepare`. Дополнительные языки используют обычные раскладки Plasma. Поддержка трекпадов добавляется к русской и английской (США). Настройки запуска Codex установщик не меняет.

## Удаление

Выполните `python3 setup.py remove`. Если адаптер всё ещё выбран в KWin, команда восстановит предыдущий метод ввода. Она также отключит службы Decktil, удалит принадлежащие установщику файлы и перечислит сохранённые локальные правки. В Steam удалите ярлык **Deck Plasma Keyboard Controls** через **Управление > Удалить стороннюю игру из библиотеки**. Если использовался `bind`, можно закрыть Steam перед удалением, чтобы убрать добавленную привязку из файла настроек.

Если раньше вы ставили адаптер вручную, сохраните такую установку отдельно. Установщик останавливается, когда встречает чужой файл с тем же именем.

Сам менеджер обновляется при открытии ярлыка из нового архива. Для удаления его из меню KDE удалите `~/.local/share/applications/io.github.YaziAranea.SteamDeckPlasmaKeyboard.desktop` и папку `~/.local/share/deck-plasma-keyboard-manager`. При нестандартном `XDG_DATA_HOME` эти пути находятся в выбранном каталоге данных.
