# Установка на Steam Deck

## Через окно настроек

1. Перейдите на рабочий стол Steam Deck. Запустите Steam и завершите игру, если она открыта.
2. [Откройте последний релиз](https://github.com/YaziAranea/Decktil/releases/latest) и скачайте **Decktil.tar.gz** в разделе **Assets**. В Dolphin выберите «Распаковать», откройте распакованную папку и запустите **Decktil.desktop**. Если KDE попросит подтвердить запуск скачанного ярлыка, выберите «Выполнить».
3. Выберите Plasma. При первой установке мастер подготовит профиль управления. В Steam откройте служебный ярлык **Deck Plasma Keyboard Controls**, перейдите к раскладке контроллера, выберите **Шаблоны → Deck Plasma Keyboard** и примените шаблон. Вернитесь в мастер для проверки.
4. В дальнейшем открывайте **Decktil** из меню приложений KDE. Выбор Steam возвращает обычный вызов родной клавиатуры. Выбор Plasma снова включает трекпады и подсказки. Архив для переключения больше не нужен.

Менеджер рассчитан на настольный сеанс KDE Plasma Wayland с установленной Plasma Keyboard. Он работает от обычного пользователя. Можно открыть его мышью или касанием экрана.

Чтобы изменить цвета, откройте **Decktil › Оформление**, выберите тему или настройте **Свой градиент** и нажмите **Применить**. Для возврата к цветам KDE выберите **Системная**. Палитра сохраняется в `$XDG_CONFIG_HOME/decktil/appearance.ini`, по умолчанию в `~/.config/decktil/appearance.ini`.

В **Decktil › Личный словарь** можно включить запоминание слов и сочетаний. При новой установке оно выключено. Пауза сохраняет уже выученные слова. Кнопка **Очистить личный словарь** удаляет их после подтверждения. Личные данные находятся в `$XDG_DATA_HOME/decktil/personal.sqlite3`, обычно это `~/.local/share/decktil/personal.sqlite3`. Этот файл сохраняется при обновлении адаптера.

## Через Konsole

Откройте Konsole в распакованном каталоге с `setup.py`. Запустите Steam и закройте работающие игры.

Понадобятся Plasma Keyboard с установленными файлами раскладок, Python 3 с PyGObject и dbus-python, GLibUnix, xdotool, kreadconfig6, kwriteconfig6, qdbus6, steamos-add-to-steam и пользовательский systemd. Для ввода нужен доступ на чтение к устройству hidraw встроенного контроллера. Для вибрации нужен также доступ на запись. Сеанс X11 и игровой режим не поддерживаются.

Для закрытия клавиатуры кнопкой **X** после удаления текста в Codex используйте обычный режим автоматического показа Plasma. В режиме «Всегда показывать» KWin может снова открыть панель, пока поле сохраняет фокус.

У установленного адаптера команды `python3 setup.py mode steam` и `python3 setup.py mode plasma` выполняют тот же выбор, что и кнопки менеджера. Команда `python3 setup.py status` показывает фактический режим.

1. Выполните `python3 setup.py prepare`. Команда создаст локальную копию выбранной настольной раскладки Steam и добавит в библиотеку служебный ярлык **Deck Plasma Keyboard Controls**.
2. Откройте этот ярлык в библиотеке Steam. Перейдите в настройки раскладки контроллера, откройте вкладку **Шаблоны / Templates**, выберите **Deck Plasma Keyboard** и примените. Если шаблон ещё не появился, полностью закройте Steam через меню **Steam > Выход**, выполните `python3 setup.py bind` и запустите Steam снова. Этот запасной способ привязывает шаблон только к служебному ярлыку. Если им пользуются несколько учётных записей или для ярлыка уже назначена другая раскладка, выберите шаблон через интерфейс Steam.
3. Верните фокус в Konsole и выполните `python3 setup.py enable`. Установщик проверит, что Steam загрузил нужный шаблон и вернул обычное управление. Затем он включит пользовательскую службу и выберет клавиатуру в KWin.
4. В настройках экранной клавиатуры Plasma включите русский язык и английский (США). Откройте текстовое поле в приложении Wayland и нажмите **Steam + X**.

Служебный ярлык запускать вручную не нужно. Храните его в библиотеке вместе с назначенным шаблоном. Адаптер получает его AppID из локальной библиотеки. Если Steam ещё не сохранил ярлык, закройте и снова откройте Steam. Если ярлык отсутствует, вручную добавьте в библиотеку как стороннюю игру исполняемый файл, путь к которому напечатал `prepare`.

Если установщик не находит используемую раскладку, сохраните её как личную настольную раскладку встроенного контроллера через Steam и повторите `prepare`. Дополнительные языки используют обычные раскладки Plasma. Поддержка трекпадов добавляется к русской и английской (США). Настройки запуска Codex установщик не меняет.

## Удаление

Выполните `python3 setup.py remove`. Если адаптер всё ещё выбран в KWin, команда восстановит предыдущий метод ввода. Она также отключит службу, удалит принадлежащие установщику файлы и перечислит сохранённые локальные правки. В Steam удалите ярлык **Deck Plasma Keyboard Controls** через **Управление > Удалить стороннюю игру из библиотеки**. Если использовался `bind`, можно закрыть Steam перед удалением, чтобы убрать добавленную привязку из файла настроек.

Для обновления выполните `python3 setup.py remove`, оставьте ярлык Steam и повторите установку из новой версии проекта. Если раньше вы ставили адаптер вручную, сохраните такую установку отдельно. Установщик останавливается, когда встречает чужой файл с тем же именем.

Сам менеджер обновляется при открытии ярлыка из нового архива. Для удаления его из меню KDE удалите `~/.local/share/applications/io.github.YaziAranea.SteamDeckPlasmaKeyboard.desktop` и папку `~/.local/share/deck-plasma-keyboard-manager`. При нестандартном `XDG_DATA_HOME` эти пути находятся в выбранном каталоге данных.
